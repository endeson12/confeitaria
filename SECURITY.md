# Política de Segurança

## Relato de vulnerabilidades

Não abra uma issue pública com detalhes sensíveis. Use a opção **Report a vulnerability** na aba Security do repositório.

Inclua uma descrição objetiva, passos para reprodução e impacto estimado. O relato será analisado antes de qualquer divulgação pública.

## Escopo

Somente a versão disponível na branch padrão recebe atualizações de segurança.
